# 八つ折りZINEメーカー

A4・A3の紙1枚から、8ページのミニブック（八つ折りZINE）を作るWebアプリです。
写真と文字を自由にレイアウトして、面付け済みのPDFで保存し、家庭のプリンタで印刷できます。

## できること

- 写真の追加（ドラッグ＆ドロップ／複数枚をまとめて1ページずつ配置）
- 見開き（P2–P3・P4–P5・P6–P7）をまたいだレイアウト
- 枠の中で写真を動かす・拡大する（写真をダブルクリック）
- トリミング、角丸・円、モノクロやリソ風などのフィルター、枠線
- 日本語フォント16種、横書き・縦書き、縁取り、背景色
- 左綴じ（横書き向け）／右綴じ（縦書き向け）の切り替え
- 本のプレビュー、印刷イメージ（面付け）のプレビュー
- PDF・PNGで保存、編集データ（.json）の書き出し・読み込み
- ブラウザへの自動保存、元に戻す・やり直し

## 写真・データの扱い

- 写真はサーバーに**送信されません**。読み込み・加工・PDF作成はすべて、使う人のブラウザの中で行われます。
- 編集内容は、その人のブラウザ（IndexedDB）にだけ自動保存されます。ほかの人からは見えません。
- 別の端末やブラウザで続きを作るときは「データ保存」で .json を書き出し、「データ読込」で読み込んでください。
- ブラウザの閲覧データを消去すると、自動保存された内容も消えます。

そのため、このサイトはサーバー側の処理を持たない静的サイトで、何人が同時に使っても互いに影響しません。

## 公開のしかた（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ローカルで試す場合は、フォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開いてください。

## 構成

```
index.html               アプリ本体（HTML・CSS・JavaScriptを1ファイルに収録）
vendor/jspdf.umd.min.js  PDF作成ライブラリ jsPDF 2.5.1（MITライセンス）
```

フォントは Google Fonts から読み込みます（インターネット接続が必要です）。

## 印刷と折り方

1. PDFを用紙サイズ（A4またはA3）・**横向き**・片面で印刷します（倍率は「実際のサイズ」がおすすめ）。
2. 縦に3本、横に1本の折り目をつけます。
3. 左右半分に折った状態で、折り目の側から横の折り目に沿って1マス分だけ切ります。
4. 上下半分に折り、両端を中央へ押して十字形にし、表紙が上に来るようにまとめれば完成です。

アプリ内の「折り方・印刷のしかた」に図つきの説明があります。
